# Security Policy

## Supported Versions

The following versions of **Capital Operator** are actively supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within the Capital Operator application, please report it privately rather than opening a public issue.

- **Security Contact**: `security@moonshinecapital.io`
- **Response SLA**: Initial triage within 48 business hours.

---

## Data Privacy & Client Lead Protection

1. **Client-Side Processing**: All diagnostic scoring algorithms, financial threshold inputs, and operational answers are computed locally in the user's browser.
2. **Lead Data Transmission**: Contact submissions collected via the blueprint dispatch modal are transmitted over TLS 1.3 to authorized endpoints only.
3. **No Financial Credentials**: The application never prompts for, processes, or stores sensitive financial credentials, borrower banking logins, or Social Security numbers.
