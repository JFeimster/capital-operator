# Partner Attribution & Tracking

## Attribution Architecture
1. **Source Tracking**: Outbound links to Tally partner and funding portals pass tracking query parameters (`?source=capital-operator&ref=blueprint`).
2. **Referral Integrity**: When an advisor refers a deal or brings a team into the Moonshine Capital ecosystem, partner attribution tags ensure recurring commission splits and relationship ownership remain protected.
3. **White-Label Support**: The diagnostic state can be shared via encoded query strings (`?blueprint=BASE64...`) allowing advisors to review client blueprints collaboratively.
