# Responsive Behavior — Capital Operator

## Breakpoint Strategy
- **Mobile (<640px)**: Single column layouts, touch targets >= 44px, sticky mobile navigation drawer with backdrop blur.
- **Tablet (640px - 1024px)**: 2-column grids for cards and stats, simplified navigation.
- **Desktop (>1024px)**: Full multi-column grids, horizontal operating rails, terminal panels with side-by-side code previews.
- **Print (`@media print`)**: Hides header, footer, interactive action bars, and navigation drawers (`no-print`), rendering clean monochrome typography (`print-only`).
