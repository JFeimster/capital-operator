# Visual Language Specification — Capital Operator

## Design Philosophy
Fintech command center with razor-sharp contrast, technical metadata, and calm, confident typography.

## UI Elements
- **Stat Cards**: Mono value display with uppercase label and micro-metric description.
- **Badges**: Subdued background with 20% opacity border matching theme token.
- **Command Panels**: Terminal-style container with title bar and mono badge code.
- **Action Buttons**: High-contrast emerald fill with dark text on primary, translucent slate border on secondary.
