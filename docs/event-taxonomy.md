# Event Taxonomy & Analytics Dictionary

## Event Categories

### Diagnostic Funnel
- `capital_operator_started`: Screen entry or primary CTA click.
- `assessment_step_completed`: Step advance with question index.
- `assessment_completed`: 12th step finalized.
- `blueprint_generated`: Results calculation complete.

### Output Actions
- `blueprint_copied`: Markdown export to clipboard.
- `blueprint_printed`: Executive PDF print preview invoked.
- `lead_submitted`: User entered business email.

### External Navigation
- `partner_cta_clicked`: Application to become a Moonshine Capital partner.
- `funding_cta_clicked`: Direct borrower financing application.
- `tool_clicked`: Outbound click to software directory or third-party tool.
