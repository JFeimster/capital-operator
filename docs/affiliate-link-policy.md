# Affiliate & Partner Link Policy

## Philosophy
Tools recommended in Capital Operator are selected solely based on operational merit, API capabilities, and commercial lending track record. 

## Disclosure Guidelines
1. **Clear Attribution**: Any link that provides economic benefit to Moonshine Capital is designated with transparent disclosure in the application.
2. **Zero Price Markup**: Users never pay a premium when using partner links; in many cases, partner codes unlock extended trials or fee discounts.
3. **Neutral Alternatives**: Every recommended tool category provides viable non-affiliate alternatives so users have complete freedom of architecture.
