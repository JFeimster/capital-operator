# Design System — Capital Operator

## Aesthetic Archetype
**Premium Dark Fintech Command Center**

### Color Tokens
- **Canvas / Background**: `#07090D` (Deep Charcoal Black), `#05070A`, `slate-950`
- **Card Background**: `slate-900/40` to `slate-900/60` with `card-glow`
- **Borders**: Subdued slate (`border-slate-800`, `border-slate-800/80`)
- **Primary Accent (Emerald)**: `emerald-400`, `emerald-500` (Automation, positive metrics, primary actions)
- **Secondary Accent (Cyan)**: `cyan-400`, `cyan-500` (AI analysis, data schema, technical stages)
- **Warning Accent (Amber)**: `amber-400` (Human checkpoints, review requirements)
- **Alert Accent (Rose/Red)**: `rose-400`, `red-400` (Operational leaks, manual friction)

### Typography
- **Headings & Body**: Plus Jakarta Sans / system sans (`font-sans`)
- **Code & Metadata**: JetBrains Mono / monospace (`font-mono`, `font-mono-code`)
