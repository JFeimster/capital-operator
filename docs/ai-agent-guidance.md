# AI Agent Guidance & Coding Rules

## Operational Guardrails for AI Coding Agents
1. **Respect Project Primacy**: Keep the application focused on the commercial debt and capital infrastructure domain.
2. **Client-Side Stability**: Never inject mandatory cloud backends for basic evaluation. The 12-question diagnostic and blueprint generator must work completely client-side.
3. **No Slop**: Maintain the dark fintech command center design tokens. Do not introduce generic white cards, rainbow gradients, or marketing clichés.
4. **Verified Tool Links**: Use authoritative URLs configured in `src/config/ctas.ts` and `src/config/tools.ts`.
5. **Always Verify Compilation**: Every change must pass `tsc --noEmit` and `npm run build`.
